🛠️ CLI Database Restoration Utility

In the event of hardware failure, power loss, or disaster recovery, use the offline command-line restoration tool located in scripts/restore_backup.py. Every restoration automatically creates an emergency rollback snapshot before touching the live database.

# Restore latest verified backup:
python scripts/restore_backup.py --latest
# Restore a specific snapshot:
python scripts/restore_backup.py --file kitab_bank_backup_20261105_120000.db
